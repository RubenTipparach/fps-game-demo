# Undercity design

The requirements live in `openspec/changes/` (proposal, design, tasks and spec deltas per
capability). This folder holds the design page that presents them.

- `undercity_systems.html` is the design page, built by `tools/design/build_page.py` from
  `src/` and the maps.
- `maps/*.svg` are the level maps, generated by `tools/levels/render_map.py` from
  `tools/levels/layouts/`. Don't edit them by hand.
